# 轻面板与便签展开：实现验收

已确认定位：随手处理事情的助手。参考 `artifacts/assistant-concept/`，实现原生便当盒「现在」面板、简化顶部状态、可调整大小的便签编辑窗口。原活动、紧凑便签、日程、设置入口保留。

## 实现

- 顶部左侧优先待处理数量，其次运行数量；右侧专注期间显示倒计时。
- 轻面板固定待处理、专注、下一项日程、当前便签位置。数据来自现有模型，无新增网络查询。
- 大窗口使用相同 NoteLibraryModel，保留 RTF 格式和原有本地保存机制。提供标题搜索、便签切换、格式工具、删除与撤销。
- 窗口间切换主动结束当前编辑并保存；隐藏编辑器只提交实际待保存的修改，防止旧内容覆盖。失去编辑焦点或隐藏时允许刷新外部修改。
- 原生窗口尺寸 900×610 内容区域，最小 760×470；轻面板内容 510×480。
- 已修复验收发现的“收回后显示旧内容”问题，并复测双向即时同步。
