# 灵动岛一体化与热区修正

用户反馈：所有工作台应始终与灵动岛连接；便签列表只有标题能点击。

实现：便签工作台改为不可拖动的无边框 NSPanel，顶部固定屏幕 maxY-32，中央连接条连接灵动岛；宽度与高度按屏幕可用区域限制。工作台随灵动岛显隐策略隐藏和恢复，屏幕配置变更时重新定位。去掉原独立窗口红黄绿控件。

列表行 label 完整 padding 后设置 contentShape(Rectangle())，选中/未选中均整行响应。新建按钮增加32×32热区，收回按钮高度34，紧凑便签标签和顶部导航补齐矩形热区。

原生验收：点击右侧留白和左下边缘均切换成功；拖动顶部后位置仍为900×650+414+32。真实截图 screenshots/anchored.png 使用独立演示数据。此次未完成额外的中文输入法组合输入和多显示器实机验证。

测试：完整75项、正式配置72项通过；新增偏移屏幕与小屏边界几何测试。Release构建和签名验证通过。未安装替换、提交或发布。
