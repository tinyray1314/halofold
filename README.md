# Halofold

Halofold 是一个原生 macOS 顶部工作中枢。它一边接住你的灵感与待办，一边跟进 Codex 等后台活动：在屏幕顶部提供本地便签、任务状态、官方周用量与本机今日 Token，并提供完成/中断语音提醒。当前发布的是本地准确版，不启用 App Sandbox，也不用于 App Store 分发。

## 安装与启动

1. 打开 `dist/Halofold.app`。
2. 因 v1 是个人使用的本地构建，若 macOS 首次拦截，请在“系统设置 → 隐私与安全性”中确认打开。
3. 应用会常驻菜单栏；设置页可控制显示内容、语音和登录后自动启动。

## 本地便签

- 按 `⌘⇧Space` 可从任意应用快速新建便签。
- 展开灵动岛后，可在“便签”和“活动”之间切换。
- 便签支持标题、加粗、引用、有序/无序列表和任务列表。
- “发现待办”会在本机扫描最近 7 天的普通 Codex 对话，展示候选项；只有经你勾选确认后才会加入“Codex 待办”便签。
- 内容自动保存在 `~/Library/Application Support/Halofold/notes.json`，不会上传或同步到云端。
- 每次覆盖主文件前会在 `~/Library/Application Support/Halofold/Note Backups/` 保留可恢复版本，自动轮换最近 30 份。
- 应用只允许一个实例运行；视觉验收使用独立的演示便签目录，不会覆盖真实便签。

应用不会读取、复制或保存 Codex 登录凭据。任务状态、标题和对话正文来自本机 `~/.codex` 的只读数据；对话正文只在你主动使用“发现待办”时在本机分析，不会上传。应用自己的设置、去重记录、断点与你录制或导入的提醒音频保存在 `~/Library/Application Support/Halofold`。

趣味音色可使用 macOS 系统语音直接生成；录音转文案仅启用与当前应用语言匹配、且设备上可用的本机语音识别。本地 AI 音色包不随应用打包或默认下载。

## 语言

Halofold 支持简体中文和英文，并默认跟随 macOS 的语言设置。也可以在“系统设置 → 通用 → 语言与地区 → 应用程序”中只为 Halofold 指定语言；重新打开应用后生效。默认提醒文案和可选系统音色会随语言匹配，用户已经修改过的提醒文案会原样保留。

## 本地开发

```bash
swift test
swift run CodexIsland
```

视觉验收模式（只显示演示数据，不读写真实 Codex 状态）：

```bash
swift run CodexIsland --demo
```

打包个人使用 `.app`：

```bash
./scripts/package_app.sh
```

## v1 数据口径

- 状态按每个对话最新一轮计算：运行中、完成、中断；完成数字表示尚未查看的新结果。
- 普通任务和自动化参与顶部计数；委派任务归入主任务，审批与守护等系统内部任务不独立计数。
- 第一次启动只纳入当时仍在运行的对话和启动后的新活动，不导入历史完成数量。
- 周用量读取已安装 Codex app-server 的只读官方接口，自动使用这台 Mac 当前登录的 Codex 账号；切换账号后会在下一次刷新时读取新账号。失败时保留最近一次本地数据并明确显示来源。
- 今日 Token 是本机当天 JSONL 增量之和，不代表账号其他设备的消耗。
- 外接无刘海屏不会生成模拟黑岛，菜单栏入口仍然存在。
