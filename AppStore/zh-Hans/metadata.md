## 描述

让后台发生的事，恰好在需要时被看见。

Halofold 是 Mac 屏幕顶部的后台状态中枢。首个数据源为 Codex，可在屏幕顶部和菜单栏中展示本机任务的运行、完成与中断状态。当任务完成或需要处理时，可通过系统语音或自定义音频提醒你，不必反复切换窗口确认进度。

主要功能：

- 实时查看运行中、已完成和已中断的 Codex 任务
- 在有刘海的 Mac 内屏上以紧凑状态岛展示信息
- 查看本机今日 Token 与 Codex 官方周用量（随本机 Codex 事件同步）
- 点击任务直接返回对应的 Codex 对话
- 从最近 Codex 对话中在本机发现待办候选，确认后加入便签
- 自定义模块顺序、紧凑程度和提醒语音
- 可选择登录 Mac 后自动启动

隐私设计：

应用需要你主动选择本机的 .codex 文件夹，并只读处理任务状态、用量数据和对话正文。对话正文仅在你主动使用“发现待办”时在本机分析。所有数据不上传服务器，也不读取或保存 Codex 登录凭据。

本应用是独立开发的第三方工具，与 OpenAI 无隶属或官方合作关系。Codex 是其各自权利人的商标。

## App Review 备注

本应用是菜单栏应用，启动后不会显示 Dock 图标。

审核步骤：

1. 请确保测试 Mac 已安装并使用过 Codex app。
2. 首次启动时，在设置页点击“选择 .codex 文件夹”。
3. 在打开面板中按 Command-Shift-. 显示隐藏项目，然后选择用户个人目录下的 `.codex` 文件夹。
4. 应用只读该文件夹中的 `state_5.sqlite` 与任务 JSONL 文件，不读取凭据，不联网传输数据。
5. 若测试机没有真实 Codex 任务数据，可使用附件中的演示视频或联系我们提供审核说明；应用二进制内的 `--demo` 参数仅用于开发截图，不作为用户功能公开。
